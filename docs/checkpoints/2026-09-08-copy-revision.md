# 2026-09-08 공개 사이트 문구 교정

상태: 콘텐츠 파일 교정과 정적 검증 완료. 새 화면의 줄바꿈, 배치, 브라우저 메타데이터 검증은 총괄의 디자인 통합 검증에서 확인한다. 이전 디자인의 검증 결과를 이번 문구에 적용하지 않는다.

## 범위와 기준

- 사용자 지시: `마포` 표현 제외, `센터 한쪽` 같은 인위적인 문구 제거, 기능을 바로 알 수 있는 제목과 자연스러운 설명.
- 수정 소유: `web/src/content/center.ts`, `web/src/content/site.ts`, `web/src/content/media.ts`, 이 문서.
- `bcs-voice/SKILL.md` 985행 전체를 분할해 읽었다. 구체적인 명사, 추상적인 분위기 문장 제거, 확인되지 않은 운영 약속 금지 규칙을 적용했다. 이번 작업은 승인된 웹사이트의 기존 사실과 UI 문구 교정이며 신규 캠페인 기획이 아니다. 사용자의 재조사·재질문 금지 지시를 우선했다.
- 한국어 소개와 운영 안내는 짧은 합니다체로 통일했다. 영어는 같은 정보를 자연스럽게 안내하도록 교정했다.
- 기존 콘텐츠와 사진 설명을 근거로 편집했다. 새 행사, 날짜, 상품, 재고, 가격, 직원 응대 범위는 추가하지 않았다.

## 검증 결과

- TypeScript로 현재 콘텐츠를 읽어 검사: 한영 각각 **91개 말단 필드 경로가 일치**. 내비게이션 7개, 프로그램 2개, 체험 2개, 기록 3개, 운영 안내 3줄 유지.
- 지도·연락처·사이트·체험 가이드 URL이 교정 전 값과 일치했다.
- 콘텐츠 전체와 한영 14개 메타데이터 조합에서 `마포`/`Mapo`가 남지 않았다.
- 메타데이터 생성부의 별도 실행 검사에서 영문 센터명은 모든 제목에 한 번만 나타났다. 첫 검사에서 기존 `Visit Bitcoin Center Seoul | Bitcoin Center Seoul`도 중복으로 잡혀 센터명이 포함된 제목에는 접미사를 붙이지 않도록 고쳤고, 재검사는 14개 모두 통과했다.
- 이 검사는 콘텐츠·제목 생성 로직을 실행한 정적 검사다. 이미지 import는 메타데이터 검사에서 최소 이미지 값으로 대체했으므로 실제 이미지와 브라우저 표시는 통합 검증 대상이다.
- `web/`에서 `./node_modules/.bin/eslint src/content/center.ts src/content/site.ts src/content/media.ts`: exit 0.
- `site.ts` 수정 후 LSP는 3초 동안 새 진단을 반환하지 않았다. LSP 통과로 기록하지 않는다. 전체 strict typecheck/build는 총괄이 통합 변경에 대해 실행한다.
- 콘텐츠 데이터 파일은 기존 한영 데이터 테이블이며 타입 구조를 분리하거나 새 추상화를 추가하지 않았다. 문자열 및 제목 조합 조건 외의 실행 흐름은 변경하지 않았다.

## 총괄에게 전달한 통합 확인 지점

- `home.tsx`의 기존 `마포의 비트코인 공간` / `A Bitcoin space in Mapo`는 총괄 소유다. `center.ts`와 별도로 제거해야 한다.
- `section-content.tsx`의 `센터에서 만나는 비트코인 작품들`도 담백한 사진 설명으로 교정한다.
- 홈·푸터·상세 페이지의 직접 입력 문구와 링크 버튼은 총괄 소유다. 콘텐츠 파일 교정만으로 전체 화면의 문구가 완료된 것으로 보지 않는다.
- 문구의 최종 화면 적합성과 사용자 승인은 이번 정적 검사와 별개다.
