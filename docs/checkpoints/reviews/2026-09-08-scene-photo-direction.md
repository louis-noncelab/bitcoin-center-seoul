# 장면과 사진 방향 — 2026-09-08

추천은 **넓은 라운지 → 손짓과 청중이 보이는 현장 사진 한 장 → 실제 작품이나 물건의 가까운 프레임**이다. 현재 사진에는 이 순서를 만들 재료가 있다. 강의실 뒷모습을 여러 장 크게 반복하거나 진열장을 다시 넓게 보여주는 방식은 감정의 강약을 만들기 어렵다.

이번 결과는 사진 선정·크롭 권장안이다. 상점이나 신청 기능의 기획이 아니다. 제품 코드, 원본 이미지, 운영 상태를 변경하지 않았고 브라우저를 사용하지 않았다. 아래 좌표는 직접 본 원본을 기준으로 정한 구현 시작점이며, 실제 페이지 크롭의 최종 검증 결과는 아니다.

## 검토 근거

- 읽은 기준: `web/DESIGN.md`, `docs/checkpoints/reviews/2026-09-08-overall-design-impression.md`, `docs/design/content-assets-2026-09-08.md`와 해당 자산 인수인계.
- `web/src/content/media.ts`의 실제 정적 import 7개를 확인하고 모두 `view_image`로 열었다. `gallery.jpeg`와 `retail.jpeg`는 추가로 원본 해상도로 열었다.
- 앞선 자산 목록이 다루는 `public/images/highlights/events/` 안에서 3개만 추가로 열었다. 전체 자산 조사나 외부 사진 탐색을 다시 하지 않았다.
- 10개 파일의 실제 치수와 포맷은 로컬 `sips -g pixelWidth -g pixelHeight -g format`으로 재확인했다. 아래 경로는 저장소 루트 `/Users/max/noncelab/center/bitcoin-center-seoul/` 기준이다.
- 사진의 색과 표현은 두 테마에서 동일하게 유지한다. Pretendard, 단색 이름, 서울 앞 자연스러운 줄바꿈, 정렬된 그리드, 8px 컨트롤·12px 미디어 모서리를 유지한다. 사진 위에 긴 문구를 얹지 않는다.

## 권장 크롭

좌표 형식은 원본 좌상단 기준 `x, y, width, height`이며 단위는 원본 픽셀이다. 크롭 파일을 새로 만든 것은 아니다. 아래의 한정된 창을 구현할 때는 원본 전체 크기를 그대로 화면 해상도로 계산하지 않는다.

| 장면 | 비율과 시작 창 | 살릴 것 / 잘릴 위험 |
| --- | --- | --- |
| 넓은 홈 라운지 | **21:9**, `0, 420, 5712, 2448` | 소파·서가·작품·청색 창을 같이 살린다. 상단 천장과 하단 앞 테이블 일부가 빠진다. 실제 원본을 `object-fit: cover`로 넣는 21:9 프레임에서는 수직 위치 약 `55%`에 해당한다. 더 얕은 배너 비율은 피한다. |
| 모바일 라운지 | **4:3**, `970, 0, 4284, 3213` | 소파·서가·창의 관계를 유지한다. 왼쪽 카운터와 작품 일부가 빠진다. 가로 위치 약 `68%`에 해당한다. 4:5로 더 좁히면 실내보다 서가·창의 일부만 보이기 쉬우므로 4:3을 우선한다. |
| 사람의 현장 | **4:3**, `0, 0, 2880, 2160`; 가로 강조가 필요하면 **3:2**, `0, 240, 2880, 1920` | 발표자의 얼굴과 든 손, 앞줄 참가자를 함께 남긴다. 3:2는 천장 일부만 덜어낸다. 좌우를 잘라 인물을 반으로 자르는 세로 크롭은 피한다. 전체 한 장의 크기를 키우는 것이 작은 얼굴을 억지로 확대하는 것보다 유효하다. |
| 왼쪽 고양이 작품 근접 — 우선 추천 | **4:5**, `480, 150, 1080, 1350` | 작품 전체와 아래 선반의 맥락이 남고 가운데 반사 심한 그림은 빠진다. 왼쪽 하단에 검은 지갑의 일부가 남을 수 있어 실제 프레임에서 가장자리를 확인한다. 작품을 더 조여 손글씨나 하단 고양이를 자르지 않는다. |
| 굿즈 선반의 물건 근접 — 대안 | **4:3**, `2040, 620, 1080, 810` | 흰 토끼 모양 장식, 유리잔 두 개, 뒤쪽 액자와 선반 경계가 남는다. 가격표 대부분은 밖으로 빠지지만 왼쪽 가장자리와 유리 반사는 확인해야 한다. 뒤 액자의 영문은 사진의 일부로 유지하고 작품명·판매명으로 전용하지 않는다. 모바일도 같은 4:3을 유지한다. |

두 근접 창의 유효 가로 해상도는 1080px이다. DPR2에서는 약 540 CSS px, DPR3에서는 약 360 CSS px 폭이 원본 확대 없는 기준이다. 작은 단독 프레임이나 그리드 한 열에 맞으며, 큰 전폭 사진으로 확대할 재료는 아니다. `sizes`에는 추가 확대·크롭을 포함한 실제 이미지 폭을 반영하고 최종 브라우저에서 디코딩된 픽셀 수를 확인한다. 일반적인 `object-position` 변경만으로는 두 근접 창의 추가 확대까지 구현되지 않는다.

`gallery`의 기존 대체 텍스트는 “그림과 판화 세 점”이므로 한 작품만 보이는 크롭에 그대로 쓰면 사실과 달라진다. 근접 사용 시의 사실적인 대체 텍스트 예시는 다음과 같다.

| 용도 | 한국어 | English |
| --- | --- | --- |
| 작품 근접 | 센터 선반 위의 비트코인을 주제로 한 고양이 그림 | A Bitcoin-themed cat illustration on a shelf at the center |
| 물건 근접 | 센터 선반에 놓인 흰 토끼 모양 장식과 유리잔 | A white rabbit-shaped ornament and glasses on a shelf at the center |

작가, 작품명, 인물 신원, 에디션, 판매 가능 여부는 사진만으로 추가하지 않는다. `experience`의 QR과 체험 안내 문구, `retail`의 가격표를 현재 결제·상품 데이터로 읽어내지 않는다. 기존 자산 인수인계에서 미확인으로 남긴 촬영·참가자 공개 권리는 이번 시각 검토로 새로 확인된 것이 아니다.

## 홈의 짧은 순서

1. **큰 이름과 실용적인 소개 다음, 넓은 라운지 한 장.** 공간의 실제 색·재료를 첫인상으로 삼는다. 한 번의 안정되는 등장 이후에는 사진이 멈춰 있어야 세부를 볼 수 있다.
2. **프로그램 영역의 `community` 한 장을 사람 장면의 중심으로.** 발표자의 손과 청중의 방향이 읽히도록 충분한 폭을 준다. 프로그램 탭을 유지하되 같은 강의 사진을 홈 저널에서 다시 크게 반복하지 않는다. 저널에 사람 장면을 옮기기로 한다면 프로그램과 저널 중 한 곳만 주인공 사진을 갖게 한다.
3. **책·지갑은 시설을 설명하는 두 보조 장면.** 라운지나 강의 사진과 같은 시각적 무게로 다시 확대하지 않는다. 기존 정보와 실제 기기 사진은 유지한다.
4. **하단에서 작품 또는 물건 하나에 가까이 간다.** 고유한 문화의 인상을 우선하면 고양이 작품 4:5, 굿즈 영역의 문맥을 우선하면 토끼·유리잔 4:3을 쓴다. 짧은 사실적 캡션과 기존 안내 링크를 같은 정렬 안에 둔다. 작품 사진을 판매 상품처럼 제시하지 않는다.
5. **방문 안내에서 끝낸다.** 사진 수를 늘리는 앨범이나 자동 재생을 추가하지 않는다. 기존 사진 앨범 아이디어는 검토용으로만 제시되었으며 이번 추천도 자동 움직임 승인을 뜻하지 않는다.

새 모션을 늘리기보다 넓은 공간·사람·가까운 물건의 크기 차이가 읽히게 한다. 등장 동작은 기존 600ms 범위의 한 번짜리 전환을 사용하고, 사람과 작품을 계속 확대하거나 패닝하지 않는다. Reduced motion에서는 즉시 정착하고 두 언어·테마에서 사진 내용과 순서를 동일하게 유지한다.

최종 한계: 이 원본들로 사람의 표정이나 손으로 지갑을 사용하는 새로운 순간을 만들 수는 없다. 다만 현재 7장의 선택과 크기·크롭만으로 공간 소개에서 현장 참여, 물건에 대한 관심으로 이어지는 훨씬 분명한 강약을 만들 수 있다.
