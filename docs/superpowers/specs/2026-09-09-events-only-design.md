# 행사 중심 개편 범위

사용자는 63a08b95cb54e06d9a00c89ae14d8d9eb1851284를 기준으로 복귀하고 최신 디자인은 유지하되 행사 표시와 관리자 등록·수정·삭제·다중 이미지 업로드만 남기도록 요청했다.

공개: 센터 소개, 프로그램/행사, 전시·체험, 활동 기록/하이라이트, 방문 안내. 행사와 하이라이트에는 독립 상세 페이지와 사진 갤러리를 제공한다. 외부 신청 링크가 있으면 원래 링크로 안내하며 자체 예약은 제공하지 않는다. 한영·라이트/다크·반응형·현재 모션과 브랜드를 유지한다.

관리: 기존 ADMIN_PASSWORD로 로그인하며 이후 요청에는 HttpOnly 세션 쿠키를 쓴다. 행사/하이라이트 두 목록에서 작성, 수정, 삭제와 여러 사진 업로드·순서 변경·제거만 제공한다. 제목, 설명, 날짜/기간, 시간/장소, 관련 링크 등 기존 공개 필드를 보존한다.

데이터: 기존 SQLite events/highlights 필드·ID를 유지하고 사진 목록 저장만 추가한다. 운영 원본에는 쓰지 않고 검증된 공개 사본에서 격리 로컬 DB를 만든다. 기존 비밀번호 값은 열람하거나 재설정하지 않으며 운영 환경의 ADMIN_PASSWORD를 그대로 공급할 수 있게 한다. 설정 누락 시 로그인은 닫힌 상태로 실패한다.

제외: 상점, 상품, 결제, 장바구니, 주문, 회원, 자체 신청/예약, 알림 발송, 관련 관리 기능 및 PostgreSQL 전환. 백업에 모두 보존한다.

검증: 원본 콘텐츠 해시와 이미지 참조, 인증/권한/CSRF, 입력 검증, 업로드 MIME·용량·경로, 삭제/수정 일관성, 실제 브라우저 CRUD와 공개 표시, ko/en·양 테마·모바일/태블릿/데스크톱. 로컬 검토본은 noindex이며 배포는 수행하지 않는다.

Owner clarification: administration is Korean-only, including /en/admin; only public pages and stored public content require ko/en. CRUD means events/highlights, not administrator accounts.

추가 디자인 지시: 방문 안내의 전화번호·이메일은 테두리 없는 아이콘·텍스트 링크로 표시한다. 클릭 영역과 키보드 포커스는 유지한다.

추가 문구·메뉴 지시: 센터 소개의 “교실에서는”을 “홀에서는”으로 변경하고 대응 영문도 hall로 맞춘다. 선택된 상단 메뉴의 파란 채움은 제거하고 글자색·밑줄·키보드 포커스로 현재 위치를 표시한다.

추가 푸터 지시: 맨 위로 링크는 테두리와 표시 문구 없이 화살표 아이콘만 보이게 하고 접근성 이름과 클릭 영역을 유지한다.
